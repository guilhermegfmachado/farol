Πώς να χρησιμοποιείτε το Farol

Τι είναι, τι δεν είναι και πώς να αξιοποιήσετε στο έπακρο σε πέντε λεπτά.

Τι είναι

  • Ένα γρήγορο εγχειρίδιο αναφοράς για εκπαιδευτικούς που εργάζονται με ετερογενείς τάξεις. Κάθε κάρτα καλύπτει ένα προφίλ μαθητή και απαντά τρεις ερωτήσεις: τι βλέπετε στην τάξη, τι μπορείτε να κάνετε σήμερα και πώς μπορεί να βοηθήσει η ΤΝ.
  • Σχεδιάστηκε για πέντε λεπτά — πριν από μια δύσκολη ώρα, πριν από μια συνάντηση με γονείς ή όταν ένας συνάδελφος χρειάζεται δεύτερη γνώμη για έναν μαθητή.
  • Είναι ανοιχτός πόρος, ενημερώνεται καθώς εξελίσσονται οι γνώσεις του συγγραφέα. Η τρέχουσα έκδοση είναι v0.1.

Τι δεν είναι

  • Δεν είναι διαγνωστικό εργαλείο. Καμία κάρτα δεν αντικαθιστά μια επίσημη ψυχολογική ή παιδαγωγική αξιολόγηση.
  • Δεν είναι κλινικό εγχειρίδιο. Η γλώσσα είναι σκόπιμα προσιτή και προσανατολισμένη στην τάξη, όχι στο ιατρείο.
  • Δεν είναι οριστικό. Τα προφίλ είναι σημεία εισόδου, όχι ετικέτες. Ένας πραγματικός μαθητής σπάνια ταιριάζει σε μία κατηγορία.

Πώς να πλοηγηθείτε

  • Στην αρχική σελίδα, επιλέξτε το προφίλ που μοιάζει περισσότερο με τον μαθητή που έχετε κατά νου. Οι σύντομες περιγραφές στις κάρτες είναι σκόπιμα άμεσες — επιλέξτε με βάση αυτό που αναγνωρίζετε, όχι το τεχνικό όνομα.
  • Μέσα σε κάθε κάρτα, οι ενότητες ταξινομούνται κατά επείγουσα ανάγκη: τι εκδηλώνεται πρώτα, τι να κάνετε μετά, πότε να παραπέμψετε τελευταίο.
  • Η ενότητα Επικοινωνία με γονείς είναι ειδική για συναντήσεις με γονείς — δεν χρειάζεται να τη διαβάσετε αν αυτό δεν είναι το πλαίσιό σας.
  • κατάλογος εργαλείων είναι μια χωριστή αναφορά — κάρτες εργαλείων με σημειώσεις απορρήτου και χαρτογράφηση προφίλ.

Σχετικά με τις ενότητες ΤΝ

  • Οι ενότητες Πού ταιριάζει η ΤΝ είναι εσκεμμένα κενές σε αυτή την έκδοση. Ο συγγραφέας παρακολουθεί εξειδικευμένη εκπαίδευση στο Σπλιτ (Ιούλιος 2026) πριν συστήσει συγκεκριμένα εργαλεία.
  • Η δομή είναι ήδη έτοιμη — κάθε εργαλείο θα έχει περίπτωση χρήσης, πρόταση prompt και σημείωση απορρήτου. Το περιεχόμενο έρχεται στην v0.2, προγραμματισμένη για Σεπτέμβριο 2026.
  • Αυτή είναι μια σκόπιμη επιλογή: ειλικρινής σιωπή αντί για αδοκίμαστες συστάσεις.

Σημείωση για τη μετάφραση

  • Οι κάρτες προφίλ παραμένουν σε αυτή την έκδοση στα πορτογαλικά. Οι ελληνικές μεταφράσεις του περιεχομένου των καρτών βρίσκονται σε εξέλιξη και θα είναι διαθέσιμες στην v0.2.
  • Η πλοήγηση, οι ετικέτες και οι σελίδες πληροφοριών είναι πλήρως μεταφρασμένες.
