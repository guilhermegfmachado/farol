FAROL
Herramientas y Enfoques para Reconocer y Orientar al alumnado, un manual de bolsillo para el aula que respeta al estudiante que tienes enfrente.
Acerca de

Este compendio reúne estrategias prácticas para docentes que trabajan con alumnos neurodivergentes, superdotados o sin dominio de la lengua de enseñanza. Cada perfil tiene una ficha de consulta rápida.

Atención, ritmo y comportamiento
No se está quieto, interrumpe, se distrae con todo → Olvida las instrucciones, pierde el material, no termina las tareas → Termina todo rápido, se aburre y molesta → Claramente capaz, pero rinde por debajo →
Lectura, escritura y organización
Evita leer en voz alta, lee despacio y con esfuerzo → Confunde letras, escribe mucho peor de lo que habla → Torpe, letra desordenada, muy desorganizado → Se pierde en las tareas de varios pasos → Cuenta con los dedos cuando sus compañeros ya calculan de memoria → Razona bien, pero confunde números y olvida las tablas →
Comunicación y lengua
Le angustian el ruido o los cambios de rutina → Muy literal, no capta lo que no se dice → Recién llegado, aún no habla el idioma de clase → Entiende más de lo que sabe decir en el idioma de la escuela →
